Module M1 & M2

Application & Testing Excellence

FastAPI Backend

High-performance asynchronous Python 3.12 service with SQLAlchemy ORM, Alembic migrations, and 6+ REST endpoints.

Glassmorphism React UI

Modern dark-mode UI with frosted glass cards, ambient glow gradients, KPI counters, and interactive incident modals.

Pytest Test Suite

9 automated test cases covering health, readiness, CRUD operations, and metrics using isolated in-memory SQLite.

Module M4, M5 & M6

Containerization, CI/CD & DevSecOps

Non-Root Dockerfiles

Backend runs under unprivileged UID 1001. Frontend uses a 2-stage build (Node 20 -> unprivileged Nginx on port 3000).

GitHub Actions Pipeline

Automated workflow running pytest, building frontend, generating Docker images, and publishing with Git SHA tags.

Trivy Security Scanning

Container images are scanned for CRITICAL and HIGH vulnerabilities before registry promotion, fulfilling DevSecOps gates.

Module M7 & M8

Terraform IaC & Kubernetes Orchestration

AWS VPC via Terraform

Provisions VPC with 2 public subnets in distinct Availability Zones, internet gateway, route tables, and EKS tagging.

AWS EKS Cluster & Nodes

Kubernetes v1.30 managed cluster with dedicated IAM roles and auto-scaling EC2 node group (2 to 4 instances).

Helm Packaging

Complete chart with 2-replica deployments, ClusterIP services, Ingress routing (/ and /api), and HPA autoscaling.
